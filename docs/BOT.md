# Bot 手册 · GitHub 情报中心

专职 Bot：`@daliy_github_post_bot`（自部署实例换成自己的 Bot）。它只做两件事：**推送**（每日总统简报）和**应答**（只读命令查询）。

## 命令清单

私聊 Bot 点输入框旁的 `/` 弹出菜单，或直接发送：

| 命令 | 回复内容 |
|---|---|
| `/brief` | 今日总统简报全文（与推送版一致） |
| `/surge` | 本轮飙升 TOP5（按星数增量） |
| `/hot` | 热度 TOP5（按热度分） |
| `/sec` | 网安焦点（安全三通道高热仓库） |
| `/watchlist` | 重点监控种子状态（巡检命中 / 保鲜数据 / 点名监控中） |
| `/stats` | 巡检状态 + 推送目标概览（所有者可见自动登记的频道名） |
| `/panel` | 面板链接 |
| `/help` | 命令说明 |

命令全部只读：不改数据、不触发巡检、不接受任何配置指令。任何人找到这个 Bot 都能查公开情报，但看不到私有频道信息——频道名只在所有者（`TG_CHAT_ID` 本人）私聊发 `/stats` 时显示。

## 每日推送

- 时机：每天北京时间 08:00 之后的第一轮巡检（约 08:17）结束时。
- 目标：私聊 + 全部已登记频道；按目标分别记状态，某个目标失败会在下一轮巡检自动补推，成功的不会重复发。
- 手动补推：`POST /api/brief/push`（需 PUSH_KEY，见 API.md），按目标 6 小时节流。

## 频道自动识别（v5.3）

**接入一个新频道只需要一步**：把 Bot 拉进频道并设为管理员。不需要报频道 ID、不需要任何配置。

原理：

1. Bot 成为频道管理员（或创建者）的瞬间，Telegram 给 webhook 发 `my_chat_member` 事件，带频道 ID 与标题，Worker 登记进推送目标（KV `intel:tgchannels`，status=active）。
2. 若 Bot 在 webhook 上线前就已经是某频道管理员（没有事件可收），该频道发出**任意一条新帖子**时，`channel_post` 事件会兜底完成登记。
3. Bot 被踢出频道或被降为普通成员，同样通过 `my_chat_member` 事件自动摘除，不再推送。
4. 多个频道可同时登记，简报会推给全部频道。

## 隐私与安全

- 频道 ID/标题只存 Worker 的 KV，不出现在面板、公开 API 或仓库里。
- Webhook 带 secret 校验，伪造请求进不来。
- Bot token 只存 Worker Secret；怀疑泄露时去 @BotFather 用 `/revoke` 轮换，然后更新 Secret 并重挂 webhook 即可。
